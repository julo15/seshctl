# Seshctl 0.8.1

## Repo colors no longer clash

With repo color coding on, two repos could end up with the same color. Each repo's color was picked without looking at the others, so with five or six repos a clash was more likely than not. Now a repo that would clash gets the free color that looks most different, and keeps it from then on. Searching History doesn't use up colors.

You'll see a one-time change: some repos that shared a color get a new one.

## Repo names as chips

In the compact layout, the repo name at the right of each row is now a soft tinted chip in the repo's color, instead of monospaced text. Tree view group headers use a larger version of the same chip, and section headers like Today and Yesterday no longer use a monospaced font.

## Fixes

- The cyan repo color is dimmer, so it no longer stands out from the rest.
