# Seshctl 0.4.0

## In-app auto-updates

Seshctl now updates itself. On launch (and once a day after that), the app quietly checks for a new release; when one is available you get a standard **Update Available** prompt with release notes and an **Install Update** button. One click downloads, verifies, swaps the app in `/Applications`, and relaunches — no DMG drag, no Gatekeeper prompt.

You can also trigger a check on demand from the menu-bar gear → **About** → **Check for Updates…**.

**One-time manual step for 0.3.0 users:** this is the first release with auto-updates baked in, so 0.3.0 itself can't update itself to 0.4.0. Download `Seshctl-0.4.0.dmg` once from the GitHub Release below and drag it over your existing install. Every release after 0.4.0 will arrive in-app.

## Row recaps for Claude Code sessions

Claude Code session rows now show the latest **recap** (the "away summary" Claude writes when a session goes idle) in the preview slot instead of the last assistant reply. The recap is usually a tighter one-line read of where the session left off. Rows with no recap yet fall back to the old preview chain unchanged.

## Under the hood

- Sparkle 2.9 embedded into the app bundle, signed with our self-signed cert + EdDSA update key.
- Appcast hosted at `https://julo15.github.io/seshctl/appcast.xml` (GitHub Pages), DMGs served from GitHub Releases.
