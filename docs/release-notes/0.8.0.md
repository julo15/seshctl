# Seshctl 0.8.0

## Search your whole history

Typing in the panel now also searches every message from every past session, not just the rows on screen. Matches show up in a **History** section, one row per session, with the matched words highlighted. Each word you type matches as a prefix, and `"quoted text"` matches a phrase. Sessions whose title matches rank first.

Claude Code deletes transcripts after 30 days, but Seshctl keeps the text. Those rows are marked **transcript deleted**, and Enter shows the conversation rebuilt from search history instead of trying to resume it.

## Retitle a session with `t`

Claude Code titles a session once, from its first prompt, so a long session keeps the name of its first task. Press **t** to have Claude suggest a title for what the session is doing now. **y** keeps it, **n** or Esc declines it. It needs the `claude` CLI installed.

## See each session's model

Rows show a small pill with the session's model, like "Opus 5.5" or "GPT-5.6 Terra". It turns amber when a session isn't on the model you usually use for that agent.

## Codex rows get titles

Codex sessions now show their thread names as row titles, instead of falling back to the branch or folder.

## Sessions in the Claude app's Code tab

Enter on a session you started in the Claude desktop app's Code tab now opens that session in the app, instead of just bringing the app forward. It also reopens sessions that have finished.

## Fixes

- **Agent badges** use the real Codex mark and Claude's brand color.
- **VoiceOver** reads rows as "Ghostty, Claude Code".
