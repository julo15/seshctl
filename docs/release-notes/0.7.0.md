# Seshctl 0.7.0

## Reopen closed sessions with `c`

Press **c** to swap the list for your closed sessions, one row per conversation, newest first. Enter resumes the selected one in a new tab, and **/** searches within it. Esc or **q** goes back to the live list. Press it again to close the panel.

## Search matches every word

Search now matches each word you type separately, across the title, repo, branch, folder and messages. `sesh dedupe` finds a seshctl session about deduplication even though the two words live in different fields.

## Pin the panel open

**Settings → Appearance → Keep panel open** turns the panel into a dashboard you can park on a spare monitor. It stays put, remembers its size and position, and dims when you're not using it. **Always in front** keeps it above other windows. While it's pinned, Seshctl appears in the Dock and Cmd+Tab. Otherwise it stays a menu-bar app.

## Rows stay still while you're using the panel

Rows used to jump to the top whenever a session updated, which could move the row you were about to click. The order now freezes while the panel is open. A pinned panel re-sorts only when you're not hovering over it or using it.

## Remote sessions open in the Claude app

If the Claude desktop app is installed, Enter on a remote row (and **w** on a bridged one) opens the session there instead of a browser tab. Remote rows show the Claude app icon.

## Fixes

- **x ends rows whose process is already gone.** Codex rows could get stuck as active after their process died.
- **Codex:**
  - Seshctl registers the SessionEnd hook, so Codex rows end when the session does.
  - Resume uses `codex resume`.
  - The prompt hook passes Codex's matcher validation.
- **Ghostty** focuses the exact split pane on builds that support it.
- **Upgrades** no longer let the hook guard uninstall Seshctl mid-upgrade.
- **New app icon** and menu bar glyph.
- **Repo colors:**
  - More distinct across repos.
  - Moved off GitHub's merged-purple and open-green.
