# Seshctl 0.6.0

## Session titles and a compact row layout

Rows now lead with the short title Claude Code writes for each session (its AI-generated title, falling back to a custom title), so you can tell sessions apart at a glance instead of reading branch names. The new default **compact** layout shows one line per session — title, repo-colored checkout folder, and the latest message — and expands the keyboard-selected row to show up to three lines of the message. Read titles dim, so bright white marks what's unread.

**Settings → Appearance → Row layout** is now a three-way picker: Compact, Stacked, or Two-column. If you'd switched the old stacked toggle off, you keep two-column.

## Status dots that mean something

- **Green, pulsing** — the agent is working.
- **Amber, with a ping ring** — the agent is waiting on you (a permission prompt, a question, or a plan to approve). This is now the loudest state on the list.
- **Gray** — idle. Gray dots fade for yesterday's and older sessions, so today's stand out.
- **Hollow gray ring** — the session has ended.

Waiting is also more accurate. Questions and plan approvals show amber immediately instead of a few seconds later, background subagents no longer flip a waiting session back to working, and the dot returns to green as soon as you answer. Idle dots no longer keep pulsing after a session stops.

## Fixes

- **Bridged sessions pair again.** Claude Code changed the transcript record that links a `/remote-control` session to its claude.ai twin, and every bridged pair had silently split into two rows. Both record shapes are now recognized. New: press **w** (or click the row's cloud glyph) to open the claude.ai side; Enter still focuses the terminal.
- **Remote rows show their latest message.** Reconnect events had buried every remote session's last reply, so remote rows were blank.
- **Smoother panel with large transcripts.** Transcript scans now read only what they need — newest-first, or only newly appended bytes — instead of re-reading 15 MB+ files on every refresh, which made the panel lag on open and close.
- **Transcript view:** links open in your browser, Cmd+C / Cmd+A work on selected text, Cmd+F opens find, and reopening the panel within a few minutes returns to the transcript you were reading.
- **Codex:** Seshctl now writes Codex's renamed `[features].hooks` flag (migrating the deprecated `codex_hooks` key), scoped to the `[features]` section so it never touches other tools' settings.
- The empty-state message no longer pushes the header to the middle of the panel.
